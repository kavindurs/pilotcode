Manual Payment Success Test

⚠️ Development Mode Only
This page is only needed because you're testing on localhost. In production, the payment gateway automatically calls the success URL.

How to test the payment flow:

  1. Go to the plans page and click "Complete Payment"
  2. You'll be redirected to the payment gateway
  3. Complete the payment on the gateway
  4. After payment, come back to this page
  5. Click the "Simulate Payment Success" button below

Test Payment Callbacks:

Use these buttons to manually trigger payment callbacks:

What happens when you click "Simulate Payment Success":

  • ✅ Payment record is created in the database
  • ✅ Property plan is updated to the selected plan
  • ✅ Session data is cleared
  • ✅ You're redirected to the plans page with success message

Production behavior:

In production, when a user completes payment on the gateway, the gateway automatically calls your success URL, which triggers the same process as clicking "Simulate Payment Success" above. The user will be redirected to the plans page with a success message.
